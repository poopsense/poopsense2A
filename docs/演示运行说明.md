# PoopSense 演示运行说明

## 上场前

1. 确认 `backend/.env.local` 已填写一枚未泄露的 DeepSeek 密钥。
2. 在项目根目录执行：

```powershell
.\start_demo.ps1 -TestModel
```

看到以下两行才表示整条演示链路可用：

```text
DEMO_SMOKE_OK ... agent_configured=true model_tested=true
PoopSense 演示已就绪：http://127.0.0.1:5173/
```

脚本发现健康服务已经运行时会直接复用，不需要再次手动执行 Uvicorn。端口被其他程序占用、数据库不可用、worker 异常或模型调用失败都会明确退出。

## 快速检查

日常检查不调用模型，也不修改业务数据：

```powershell
.\check_demo.ps1
```

上场前检查真实模型：

```powershell
.\check_demo.ps1 -TestModel
```

## 演示顺序

1. 让浏览器停留在首页，在 `backend` 目录执行 `.\.venv-runtime\Scripts\python.exe scripts\simulate_dry_flow.py`。
2. 首页自动出现偏干硬结果卡通动画，随后自动进入 Agent 医生并生成补水建议。
3. Agent 返回取水许可后，页面展示“准备取水”。第一次点击只展开安全确认，不会运动。
4. 确认水杯已放在标定位置、机械臂周围无人和障碍物；点击“确认开始取水”后仅执行取杯、夹紧、提起并保持。
5. 需要时点击“停止机械臂”。当前演示不移动、不递水、不松爪；完整 VBot 递水链路不在本轮演示范围。

脚本只模拟传感结果，不会启动真实机械臂。若机械臂上位机未以 `--live` 模式连接到 `http://localhost:5000`，最终确认会被后端安全拒绝。
5. 我的：展示设备、家庭授权、通知、Soul 历史、Agent 行动和能力目录。

## 常见问题

- `WinError 10048`：已有后端占用 8000，不要重复启动；改用 `start_demo.ps1`。
- `MODEL_NOT_CONFIGURED`：`.env.local` 中没有有效密钥，修改后需要重启后端。
- 网页能打开但数据异常：执行 `check_demo.ps1`，再查看 `.runtime-logs` 中最新日志。
- 任何发到截图、聊天或代码仓库里的密钥都视为已泄露，必须在供应商控制台撤销并更换。
